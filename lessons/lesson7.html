第 7 课：让场景能"点"——鼠标拾取与信息卡

数字孪生和"3D 视频"的分水岭就在这课：点一栋楼，它认识你。学完你能做出点击弹信息卡 + 悬停高亮——评委最爱玩的功能。

先玩一玩 👇（鼠标悬停任意楼会变琥珀色；点击弹出信息卡）

先点"布置校园"

💡 这张卡片是网页元素(DOM),不是画在地球上的——三维与二维的联动

一、思路：三步完成"点击"魔法

① 监听鼠标点击,拿到屏幕坐标→ ② scene.pick 问引擎:这个点压到了谁?→ ③ 从被点实体身上取出 myInfo,填进信息卡

二、代码逐行解读

// 第①②步:装一个"鼠标监听器",专门监听左键点击
const handler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas);

handler.setInputAction(function (movement) {
  // movement.position = 点击位置的屏幕坐标(x,y 像素)
  const picked = viewer.scene.pick(movement.position);  // 问引擎:这点压到了谁?

  // picked 可能是 undefined(点到了空地),picked.id 才是实体本身
  const ent = picked && picked.id;

  if (!ent || !ent.myInfo) {   // 点到空地或点到树/标签等"无证人员"
    hideCard();                // → 收起信息卡
    return;
  }

  // 第③步:拿出第5课"贴"上去的身份证,填卡片
  showCard(ent.myInfo);

  // 顺手给楼换个高亮色(想还原?把原色存起来,见下面"悬停"段)
  ent.polygon.material = Cesium.Color.fromCssColorString('#ffd54f').withAlpha(0.8);

}, Cesium.ScreenSpaceEventType.LEFT_CLICK);   // 监听的事件类型:左键单击
  1. ScreenSpaceEventHandler —— "屏幕事件监听器"。除了 LEFT_CLICK，还能监听右键、双击、鼠标移动（马上用到）。
  2. scene.pick(屏幕坐标) —— 引擎的"射线检测"：从相机向点击处发一条看不见的射线，报告第一个撞到的物体。这是所有三维交互的基石。
  3. ent.myInfo —— 第 5 课埋的伏笔兑现！实体身上带着自己的数据表，点击时直接读。
  4. ent.polygon.material = ... —— 整体替换材质实现高亮。改颜色不是"画上去"，而是"换一张皮肤"。

三、悬停高亮：还要学会"还原"

悬停（MOUSE_MOVE）高亮的难点不是"变黄"，是移开后要变回去——所以必须先把原色存起来：

let hovered = null;                       // 记住"现在悬停在哪栋"

handler.setInputAction(function (movement) {
  const picked = viewer.scene.pick(movement.endPosition);  // 注意:移动事件叫 endPosition
  const ent = picked && picked.id && picked.id.myInfo ? picked.id : null;

  if (hovered !== ent) {                   // 悬停目标变了才干活(省性能)
    if (hovered) {                         // 还原上一栋
      hovered.polygon.material = Cesium.Color.fromCssColorString(hovered.myInfo.color).withAlpha(0.8);
    }
    hovered = ent;
    if (hovered) {                         // 高亮新一栋
      hovered.polygon.material = Cesium.Color.fromCssColorString('#ffd54f').withAlpha(0.75);
    }
  }
}, Cesium.ScreenSpaceEventType.MOUSE_MOVE);
鼠标移动事件每秒触发几十次，pick 是有成本的。教学版靠"目标变了才处理"已经够用; 真实项目加了 60ms 节流(两次检查间隔小于60ms直接跳过),这两个词(节流/防抖)面试也常问。

四、信息卡是"网页"，不是"三维"

看本页演示:卡片是普通 HTML div(圆角、阴影、字号都是 CSS),Cesium 只负责三维画面。 三维引擎管"世界",网页管"界面",两者通过 JS 变量(实体数据)握手——所有数字孪生大屏都是这个套路: 中间一块三维画布,四周一圈网页面板。

真实项目 main.js 搜 LEFT_CLICK:点击楼先 flyTo 聚焦(下下节还没讲, 其实就是第2课的相机飞行+一个 HeadingPitchRange 控制距离),再 ui.showBuilding(b) 弹出更豪华的卡片(带 ECharts 图表,第10课)。

📝 动手作业

  1. 把本课代码搬进你的 my1.html,实现:点击楼 → alert(ent.myInfo.name + ' 到此一游!')——一行代码验证拾取通了。
  2. 升级成页内信息卡(照抄本页 showCard/hideCard,或自己写个更漂亮的)。
  3. 挑战:点击后相机 viewer.flyTo(ent, { offset: new Cesium.HeadingPitchRange(0, Cesium.Math.toRadians(-55), 250) }) 飞过去围观这栋楼(HeadingPitchRange = 朝向/俯角/距离,翻译成人话:斜 55° 看,离 250 米)。

检查点

1. 点到空地时 scene.pick 返回什么？代码怎么防崩？

返回 undefined。必须先判断 if (!ent || !ent.myInfo) 再取属性，否则"Cannot read property of undefined"——新手最常见的崩溃。

2. 悬停高亮为什么必须先"存原色"？

因为鼠标移开时引擎不会自动还原，得自己换回去；原色没存，就永远还原不了（或还原错）。

3. 信息卡是画在三维场景里的吗？

不是。是普通网页 div 叠在画布上方。三维管世界、网页管界面，这是所有数字孪生大屏的架构。
