一、数字面板：DOM + 定时器 + 随机游走

面板数字的"实时感"来自三件套：定时器（每 2 秒跑一次）、随机游走（在旧值上加一点小随机，而不是完全随机——曲线才像真的）、DOM 更新（把数字写进网页元素）。

// ① 随机游走:在旧值附近小步乱走(比纯随机真实一万倍)
function walk(v, step, min, max) {
  v += (Math.random() - 0.5) * step;   // 上下随机 ±step/2
  return Math.min(max, Math.max(min, v)); // 别走出边界
}

// ② 状态对象:全校指标的"账本"
const stats = { people: 8600, power: 420 };

// ③ 每 2 秒:更新账本 → 刷新面板
setInterval(() => {
  stats.people = walk(stats.people, 60, 8200, 9200);
  stats.power  = walk(stats.power, 12, 350, 520);
  document.getElementById('stPeople').textContent = Math.round(stats.people).toLocaleString();
  document.getElementById('stPower').textContent  = stats.power.toFixed(1);
}, 2000);
  1. Math.random() - 0.5 —— 产生 −0.5~+0.5 的随机数，乘 step 就是"小步"。纯随机（8600 跳到 200）一看就假，游走才有"传感器数据"的味道。
  2. toLocaleString() —— 数字加千分位（8,634）。toFixed(1) —— 保留 1 位小数。展示细节决定"像不像真的"。
  3. document.getElementById('xx').textContent = ... —— JS 改网页内容的最基本动作：找到元素、改文字。三维与面板就是靠这种方式各自刷新的。

二、ECharts 三步走：init → setOption → 更新数据

// ① 初始化:把一个 div 变成图表
const chart = echarts.init(document.getElementById('chart'));

// ② 配置(setOption):声明"这是条折线图、x 轴是时间、渐变填充..."
chart.setOption({
  grid: { left: 44, right: 12, top: 14, bottom: 24 },   // 图在框里的位置(留出坐标轴空间)
  xAxis: { type: 'category', data: [] },                 // x 轴:类别轴(放时间文字)
  yAxis: { type: 'value' },                              // y 轴:数值轴
  series: [{                                             // 数据系列:一条平滑折线
    type: 'line', data: [], smooth: true, symbol: 'none',
    lineStyle: { color: '#0891b2', width: 2 },
    areaStyle: { color: { type: 'linear', x: 0, y: 0, x2: 0, y2: 1,   // 底部渐隐填充
      colorStops: [{ offset: 0, color: 'rgba(8,145,178,.35)' },
                   { offset: 1, color: 'rgba(8,145,178,0)' }] } },
  }],
});

// ③ 每秒:推一个新点,超过 40 个就丢最老的,再 setOption 更新
setInterval(() => {
  labels.push(now());  values.push(stats.power);
  if (labels.length > 40) { labels.shift(); values.shift(); }
  chart.setOption({ xAxis: { data: labels }, series: [{ data: values }] });
}, 1000);
  1. ECharts 的使用心法：先声明"图长什么样"（setOption），之后只喂数据。改数据不用重建图，再调一次 setOption 覆盖即可。
  2. shift() —— 数组丢掉第一个元素。"推一个、丢一个" = 滚动窗口，监控曲线的标准做法。
  3. areaStyle 的渐变（上实下虚）是"科技感曲线"的灵魂配方，直接抄。

检查点

1. 为什么用"随机游走"而不是纯随机数？

真实传感器读数是连续缓变的（这一秒和上一秒相近），游走模拟这种惯性；纯随机大跳看起来一眼假。

2. ECharts 图表创建后,更新数据的正确姿势是？

改数据数组后再次 setOption（覆盖 xAxis.data 和 series.data），不需要（也不应该）重新 init。

3. 三维里的告警和面板上的数字是怎么"联动"的？

没有直接联动——都读同一个数据源（账本），谁变了各自刷新自己那部分。单一数据源是大型界面的标配架构。
