第 6 课：道路、水面与绿化——校园的"血肉"

只有楼的城市是孤岛。这课学两个新形状：走廊 corridor（带宽度的路）和椭圆 ellipse（湖/操场），再送一排"程序化种树"。

先玩一玩 👇（按 1→2→3→4 的顺序点，建出一座小镇）

每个按钮可以反复点(位置会错开)

一、走廊 corridor：自带宽度的路

第 5 课的多边形是"把点围成面"，走廊则是"把一串点连成线，再给线一个宽度"——正是路的逻辑：

viewer.entities.add({
  corridor: {
    positions: [                          // 路的"骨架":一串拐点(局部米坐标→经纬度)
      Cesium.Cartesian3.fromDegrees(...offsetLL(-150, 0)),
      Cesium.Cartesian3.fromDegrees(...offsetLL(0, 0)),
      Cesium.Cartesian3.fromDegrees(...offsetLL(0, 120)),
    ],
    width: 12,                            // 路宽 12 米(真实米数,别忘单位)
    height: 0.5,                          // 稍微抬一点,避免和地面"打架"闪烁
    material: Cesium.Color.fromCssColorString('#3b5364').withAlpha(0.95),
  },
});
  1. positions —— 路的走向，想拐弯就多点几个点（真实项目的主环路用了 14 个拐点）。
  2. width: 12 —— 双向两车道约 7 米，主干道 10~12 米，注意这是总宽不是半宽。
  3. height: 0.5 —— 小抬升 0.5 米。两个面完全重合时 GPU 会"闪烁打架"（术语 z-fighting），错开一点就相安无事。真实项目道路抬 1.2 米，同理。

二、椭圆 ellipse：湖、操场、广场一把抓

// 湖(偏东 120 米,偏北 60 米;长轴 70 米 × 短轴 50 米)
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(...offsetLL(120, 60), 0.6),
  ellipse: {
    semiMajorAxis: 70,    // 长半径(米) — 椭圆"躺着"方向的一半
    semiMinorAxis: 50,    // 短半径(米)
    material: Cesium.Color.fromCssColorString('#0277bd').withAlpha(0.75),
    outline: true,
    outlineColor: Cesium.Color.fromCssColorString('#4fc3f7').withAlpha(0.5),
  },
});

// 运动场 = 两层椭圆叠出来:外圈红色跑道 + 内圈绿茵场
// 外圈
{ ellipse: { semiMajorAxis: 60, semiMinorAxis: 45, material: 红色 } }
// 内圈(同心,略小)
{ ellipse: { semiMajorAxis: 46, semiMinorAxis: 31, material: 绿色 } }
  1. 注意是半径不是直径：想要 140 米长的湖，semiMajorAxis 写 70。
  2. 两个半径写一样就是正圆（广场）。
  3. "叠"是三维场景造型的万能手法：跑道+草皮、湖+岸、屋顶+楼体，全是叠出来的。

三、程序化种树：让代码替你干活

一棵棵写坐标太蠢了。"沿着这条路每隔 15 米种一棵"这种规律，正是循环最擅长的：

for (let x = -140; x <= 100; x += 15) {          // 从西到东,步长15米
  const [lon, lat] = offsetLL(x, 10);            // 路北侧 10 米处
  viewer.entities.add({
    position: Cesium.Cartesian3.fromDegrees(lon, lat, 3), // 树中心离地3米
    cylinder: {                                  // 圆柱体当树冠
      length: 6, topRadius: 2.2, bottomRadius: 3, // 高6米,上小下大更像树
      material: Cesium.Color.fromCssColorString('#2e9e5b'),
    },
  });
}
  1. cylinder 圆柱：上半径小、下半径大，就有"树冠"的味儿。
  2. 真实项目更进一步：在林地多边形里随机撒树（还避开楼），300+ 棵树一个循环搞定——这就是"程序化生成"，答辩时可以大方讲。
真实项目 sceneObjects.js 里:搜 corridor 能找到 6 条道路,搜 ellipse 能找到 两个运动场/两个湖/圆形广场,搜 cylinder 就是那片树林。和本课唯一区别:数据全部来自 campusData.js 的表。

  2. 在楼群里挖一个湖,并给湖配一圈"绿化岸"(提示:先画一个大一圈的深绿椭圆垫底,再画水面)。
  3. 挑战:写一个双层循环 for(x...){ for(y...){...} },种出一个 5×5 的树阵。

检查点

1. 为什么道路要 height: 0.5 抬起来？

避免和地面完全重合导致的 z-fighting 闪烁（两个面争抢"谁在上面"，GPU 随机翻面）。

2. 想画直径 60 米的圆形广场，两个 axis 各写多少？

都写 30（半径 30 = 直径 60；两个相等即为正圆）。

3. "跑道+内场"用了什么造型思想？

叠加：两个同心椭圆，外层大（跑道色）、内层小（草色），叠出真实运动场的层次。
