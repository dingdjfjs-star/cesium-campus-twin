第 5 课：数据驱动——整个课程最重要的思想

前面画楼都是"一栋一栋手写"。这课把楼写进表格（数组），用循环批量生成。学完这课，"换一所学校"对你来说只是"换一张表"。

先看效果 👇

试试:先盖图书馆再盖全部,感受"循环"的威力

一、先解决上节课的痛：offsetLL 换算函数

上节课为了画 60 米宽的楼，手算了 0.00031° 这种数字——累且容易错。现在写个函数一劳永逸：

const CAMPUS = { lon: 114.30, lat: 30.50 };   // 校园原点(一个点撬动整座校园!)

// 把"向东 dx 米、向北 dy 米"翻译成经纬度
function offsetLL(dx, dy) {
  const lon = CAMPUS.lon + dx / (111320 * Math.cos(CAMPUS.lat * Math.PI / 180));
  const lat = CAMPUS.lat + dy / 111320;
  return [lon, lat];
}

// 用法:想在原点"东边60米、北边40米"处定位 → offsetLL(60, 40)
  1. 从此写坐标只说米：dx 向东、dy 向北（数学课的坐标系，原点在校园中心）。
  2. 纬度方向：111320 米 = 1 度（上节课的口诀）。经度方向多乘一个 cos(纬度)，就是把"越往两极经线圈越小"翻译成代码。
  3. 妙处：整座校园所有楼都相对"原点"定位。想搬家？只改 CAMPUS 两个数字，全校楼整体平移到地球任何角落。这就是"一个点撬动整座校园"。

  { name: '教学楼A', dx: -60, dy:  40, w: 44, d: 22, floors: 5, color: '#3fbdf2' },
  { name: '教学楼B', dx:  10, dy:  40, w: 44, d: 22, floors: 5, color: '#3fbdf2' },
  { name: '实验楼',   dx:  80, dy:  40, w: 40, d: 26, floors: 6, color: '#26c6da' },
  { name: '图书馆',   dx:   0, dy: -30, w: 48, d: 30, floors: 5, color: '#7fd8ff' },
  { name: '行政楼',   dx: -70, dy: -60, w: 36, d: 22, floors: 4, color: '#80cbc4' },
  { name: '食堂',     dx:  60, dy: -60, w: 32, d: 24, floors: 2, color: '#ffb74d' },
  { name: '学生公寓1', dx: -110, dy: -10, w: 16, d: 34, floors: 6, color: '#66bb6a' },
  { name: '学生公寓2', dx: -110, dy:  40, w: 16, d: 34, floors: 6, color: '#66bb6a' },
];

这张表就是"世界的设计图"。每行一个对象（一张小表），描述一栋楼。看不懂语法？拆开：

  • 最外层方括号 [ ... ] 表示"一排东西"（数组），里面用逗号分隔 8 张小表；
  • 每张小表 { name: ..., dx: ... } 就是你第 3 课学的对象"填表"写法。

三、循环：一行代码盖八栋楼

for (const b of BUILDINGS) {          // 依次取出每栋楼的数据,叫它 b
  const [lon, lat] = offsetLL(b.dx, b.dy);        // 米 → 经纬度
  const h = b.floors * 3.2;                        // 层数 → 楼高(米)
  const halfLon = b.w / 2 / 95300;                 // 宽的一半 → 经度差
  const halfLat = b.d / 2 / 111320;                // 深的一半 → 纬度差

  const ent = viewer.entities.add({
    polygon: {
      hierarchy: new Cesium.PolygonHierarchy([
        Cesium.Cartesian3.fromDegrees(lon - halfLon, lat - halfLat),
        Cesium.Cartesian3.fromDegrees(lon + halfLon, lat - halfLat),
        Cesium.Cartesian3.fromDegrees(lon + halfLon, lat + halfLat),
        Cesium.Cartesian3.fromDegrees(lon - halfLon, lat + halfLat),
      ]),
      height: 0,
      extrudedHeight: h,
      material: Cesium.Color.fromCssColorString(b.color).withAlpha(0.8),
      outline: true, outlineColor: Cesium.Color.WHITE.withAlpha(0.4),
    },
  });

  // 楼顶名牌
  viewer.entities.add({
    position: Cesium.Cartesian3.fromDegrees(lon, lat, h + 12),
    label: { text: b.name, font: '13px sans-serif', fillColor: Cesium.Color.WHITE,
             showBackground: true, backgroundColor: Cesium.Color.BLACK.withAlpha(0.6) },
  });

  ent.myInfo = b;   // ★ 关键伏笔:把整张小表"贴"在实体身上,第7课点击时取用!
}
  1. for (const b of BUILDINGS) —— "把 BUILDINGS 里的东西一个个拿出来，每次叫 b"。循环体（大括号里）就写"画一栋楼"，和第 4 课几乎一样，只是所有数字都从 b 身上取。
  2. b.floors * 3.2 —— 数据表里存的是层数（人话），高度用时再算。好数据表存"业务概念"，不存"渲染细节"。
  3. ent.myInfo = b —— 本课最重要的一行。给实体挂一个自定义属性，把它的"身份证"（名字、层数、颜色……）随身携带。第 7 课鼠标点到这栋楼时，就能从 ent.myInfo 里读出全部信息弹信息卡。

四、为什么说这是"最重要的思想"？

写法画 8 栋楼加第 9 栋换学校
一栋栋手写8 段几乎重复的代码再抄一段全部重写 💀
数据驱动1 个循环表里加一行 ✅换一张表 + 改原点 ✅
真实项目的 campusData.js 就是这张表的"满血版"(41 栋楼,每行多了 id/rot 旋转角/roof 屋顶色/ usage 用途/capacity 人数/powerBase 功率),画图代码在 sceneObjects.js。 我们把一张卫星图变成三维校园,改的只是这张表——代码一行没动。答辩讲"架构设计"时就讲这个。

📝 动手作业（今天的作业=给你未来项目打地基）

  1. 把本课 BUILDINGS 表复制进你的 my1.html，删掉一半楼，改成你自己起的名字。
  2. 在表里加一行你想要的楼（比如"电竞馆"，10 层，紫色 #ab47bc），位置别和其他楼重叠。
  3. 把 CAMPUS.lon/lat 改成你学校的真实坐标（第 2 课学过怎么查）——你的校园搬回家了！
  4. 思考题（不用写码）：想让楼"斜着放"（比如宿舍群朝北东 30°），数据表该加什么字段？

检查点

1. 为什么数据表里存 floors（层数）而不是直接存 height（米）？

层数是"业务概念"，人一看就懂、也好从资料里录入；米是"渲染细节"，让代码去换算。数据和渲染各司其职。

2. ent.myInfo = b 这行为什么重要？

它把数据表"缝"在了实体身上，让"画出来的楼"和"它的信息"永远绑在一起——第 7 课点击楼弹出信息卡，全靠它。

3. 换一所学校，最少要改几处？

两处：CAMPUS 原点坐标（搬到哪）+ BUILDINGS 表（长什么样）。渲染代码零修改。
