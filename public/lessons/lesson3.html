第 3 课：实体（Entity）——往地球上放东西

地球有了，现在往上面"摆东西"。一栋楼、一个摄像头图标、一条路……在 Cesium 里都叫实体。这课学会三种最常用的：点、盒子、文字标签。

先玩一玩 👇（点下面的按钮，然后自己转视角看效果）

按钮可以连点多下试试 · 左下角显示当前实体数量

一、JS 对象的"填表"写法（1 分钟扫盲）

创建实体时你写的代码长这样：{ position: ..., box: ... }。这对大括号叫对象，本质是填一张表：

{
  position: 某个坐标,   // 表格字段1: 放在哪
  box:      某个盒子,   // 表格字段2: 长什么样
}

规则就两条：字段名和值之间用冒号，字段之间用逗号，最后一个字段后面不写逗号。Cesium 读这张表，就知道你要什么样的东西。

二、三种实体，逐个拆解

① 点（point）——最简单的实体

viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(114.30, 30.50, 10), // 放在哪(离地10米)
  point: {                       // "我要一个点"
    pixelSize: 14,               // 大小:14 个屏幕像素(固定大小,不随远近变)
    color: Cesium.Color.RED,     // 颜色:红
  },
});
  1. viewer.entities.add({...}) —— entities 是 viewer 身上的"实体仓库"，add 就是往里加一个。它会把创建的东西返回给你，接住就能以后操作它：const p = viewer.entities.add(...)。
  2. position —— 上课学的坐标写法原封不动用上了。
  3. pixelSize: 14 —— "像素"单位意味着：凑近看它也不会变大，像个图钉。适合做摄像头图标、告警点。

② 盒子（box）——有了体积！

viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(114.30, 30.50, 20), // 盒子中心(注意:是中心,会陷地一半)
  box: {
    dimensions: new Cesium.Cartesian3(40, 20, 30), // 长40米 × 宽20米 × 高30米(真实尺寸!)
    material: Cesium.Color.CYAN.withAlpha(0.8),    // 材质:青色,透明度80%
  },
});
  1. dimensions —— 又见 Cartesian3，这次三个数字的含义变成了长、宽、高（米）。和上一课"经纬度翻译官"是同一个类，不同场合含义不同，别慌。
  2. position 是盒子的"几何中心"——所以高度给 20，高 30 米的盒子会一半埋进地里。想让盒子坐地上：中心高度 = 盒高 ÷ 2。
  3. withAlpha(0.8) —— 半透明。0 全透明（隐身），1 不透明。数字后一个常见的坑：Cesium.Color 必须大写 C，写成 cesium.color 直接报错。

③ 文字标签（label）——给东西挂名牌

viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(114.30, 30.52, 60),
  label: {
    text: '我的第一个标签',                      // 显示的文字
    font: '20px sans-serif',                    // 字号字体
    fillColor: Cesium.Color.YELLOW,             // 字色
    showBackground: true,                       // 要背景块
    backgroundColor: Cesium.Color.BLACK.withAlpha(0.6),
  },
});

label 就是"挂在天上的名牌"。真实项目里每栋楼头顶的名字、巡逻车跟随的名字，全是它。

组合技：一个实体可以同时带多种外观！比如既有点又有标签： { position, point: {...}, label: {...} } —— 一张表填两个字段而已。
真实项目 sceneObjects.js 里的行道树就是一排 cylinder(圆柱)实体; 监控摄像头图标是画在 canvas 上再贴给 billboard(布告板)实体。原理与本课完全相同,只是"形状"换了个字段。

📝 动手作业（在 my1.html 里继续加）

  1. 放一个30×30×60 的红色盒子在你学校坐标上，调好高度让它坐在地上而不是半埋（高度该填多少？）。
  2. 给这个盒子配一个标签，写上"我的宿舍"。
  3. 用 for 循环一口气放 10 个盒子，位置在经度上每次 +0.001（约 100 米），排成一条线。 提示：for (let i = 0; i < 10; i++) { ... fromDegrees(114.30 + i * 0.001, 30.50, h) ... } —— 这就是下一课"一片楼"的预告！

检查点

1. 高 60 米的盒子想"坐"在地上，position 的高度填多少？

30。position 是几何中心，中心离地 30 米，盒子正好下缘贴地。

2. pixelSize 和 dimensions 的本质区别？

pixelSize 是屏幕像素，拉远拉近大小不变；dimensions 是真实米数，凑近看会变大。做"图标"用前者，做"实体物"用后者。

3. 想让一个实体既有图标又有名字，要创建两个实体吗？

不用。一张"表"里同时写 point/billboard 和 label 字段，它们共享同一个 position。
