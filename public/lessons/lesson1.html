第 1 课：8 行代码，看到你的第一个地球

今天的目标：亲手让 Cesium 跑起来，学会"开飞机"，并且第一次读懂每一行代码的含义。

先看效果 👇（这就是你等下要亲手写出来的东西）

先用鼠标玩 1 分钟：左键拖动转地球 · 滚轮缩放 · 中键拖动倾斜

一、网页是怎么"组成"的（30 秒扫盲）

任何网页都由三种文件拼成，记住这个比喻就够了：

文件比喻管什么长什么样
HTML🦴 骨架页面上有哪些东西、摆在哪<div>...</div> 一层层嵌套的标签
CSS💄 化妆品颜色、大小、位置、好看width: 100% 这样的"属性: 值"
JavaScript⚡ 动作点击反应、动画、连数据new Cesium.Viewer(...) 这样的指令

本课页面就是一个 HTML 文件：public\lessons\lesson1.html（用编辑器打开它，下面讲的所有代码都在里面）。

二、让地球出现的三板斧（逐行解读）

把 Cesium 跑起来只需要三步：① 引入引擎的样式表 → ② 引入引擎本体 → ③ 指定一个 div，让引擎往里面画地球。

<!-- 第①步：引入 Cesium 自带的样式(它的小工具按钮需要) -->
<link href="../cesium/Widgets/widgets.css" rel="stylesheet">

<!-- 第②步：告诉引擎"资源文件夹在哪"，再引入引擎本体 -->
<script> window.CESIUM_BASE_URL = '../cesium/'; </script>
<script src="../cesium/Cesium.js"></script>

<!-- 第③步：准备一个空盒子(div)，地球将画在里面 -->
<div id="globe"></div>

<script>
  // 指挥引擎：找到 id 为 globe 的盒子，把它变成一个三维地球
  const viewer = new Cesium.Viewer('globe', { /* 选项 */ });
</script>
  1. <link ... widgets.css> —— 引样式表。rel="stylesheet" 意思是"这是一个样式表"。Cesium 的控件按钮长相由它定义。
  2. window.CESIUM_BASE_URL = '../cesium/' —— 必须在引入 Cesium.js 之前写。它告诉引擎：图片、字体等资源放在哪个文件夹。本项目把整套 Cesium 拷在了 public\cesium\，所以这里填相对路径 ../cesium/（从 lessons 文件夹往外找）。
  3. <script src="../cesium/Cesium.js"> —— 引入引擎本体。执行完这一行，你的页面里就多了一个全局工具箱 Cesium，后面所有功能都从它身上拿。
  4. <div id="globe"> —— 一个空容器。id 是给它起的唯一名字，JS 靠名字找到它。
  5. const viewer = new Cesium.Viewer('globe', {...}) —— 全课核心！new 的意思是"用 Cesium 工具箱里的 Viewer 模具，造一个地球实例"，造好后用变量 viewer 拿着它的遥控器——以后想操控地球，都是 viewer.某个功能()。

那个 { /* 选项 */ } 里都关了什么？

打开 lesson1.html 源码，你会看到一长串选项。Cesium 默认会在页面角落加一堆小工具（时间轴、搜索框……），教学阶段我们全关掉，只留干净的地球。每个选项的中文意思：

const viewer = new Cesium.Viewer('globe', {
  baseLayerPicker: false,      // 右上角"切换地图样式"按钮
  geocoder: false,             // 搜索框(搜地名)
  homeButton: false,           // "回家"按钮
  sceneModePicker: false,      // 2D/3D 切换按钮
  navigationHelpButton: false, // 帮助按钮
  animation: false,            // 左下角时间动画控件
  timeline: false,             // 底部时间轴
  fullscreenButton: false,     // 全屏按钮
  infoBox: false,              // 点击实体弹出的小信息框(第7课我们自己做一个)
  selectionIndicator: false,   // 点击实体时的绿色选中框
});
真实地图影像来自 Cesium 官方服务器，需要联网。如果只见深色球体没有影像，多半是网络问题——不影响学后面的课。

三、学会"开飞机"：鼠标操作

操作效果比喻
左键按住拖动转动视角 / 平移脑袋左右转头
滚轮拉近 / 拉远向前走 / 向后退
中键按住上下拖（或 Ctrl+左键拖）俯视 ↔ 侧视倾斜低头 ↔ 抬头

上方演示区的四个按钮，用的就是接下来这句"魔法咒语"——让相机飞到指定地点：

function flyTo(lon, lat, height) {
  viewer.camera.flyTo({
    destination: Cesium.Cartesian3.fromDegrees(lon, lat, height), // 目的地(经度, 纬度, 高度米)
  });
}
  1. viewer.camera —— 相机。三维世界的"眼睛"，你看到的画面由它的位置和朝向决定。
  2. flyTo({...}) —— 不是瞬移而是平滑飞过去（默认约 3 秒），答辩演示的"电影感"就靠它。
  3. Cesium.Cartesian3.fromDegrees(经度, 纬度, 高度) —— 把人类习惯的"经纬度+高度"翻译成引擎内部的坐标。你只需记住：这是给地球上某个点定位的标准写法，下节课细讲。
真实项目的 createScene.js 里,创建 Viewer 的选项几乎一模一样,只多了一条 baseLayer: false(不要卫星影像,改用纯色科技感地球)+ creditContainer(把版权文字藏到看不见的 div)。

四、检查点

1. 为什么 CESIUM_BASE_URL 必须写在引入 Cesium.js 之前？

引擎一被加载就会立即去找自己的资源文件夹（图片/字体等），地址必须提前备好——就像快递员出发前你得先把新地址给他，出发后再改就晚了。

2. viewer 这个变量在整个项目里的角色是什么？

遥控器/总入口。相机、场景、实体集合……都从它身上一层层点出来，比如 viewer.camera、viewer.entities（第 3 课登场）。

3. 想让地球默认打开就在珠峰上空，该写哪句？

viewer.camera.flyTo({ destination: Cesium.Cartesian3.fromDegrees(86.925, 27.9881, 15000) }); （或用 setView 瞬移过去，两个的区别下节课讲。）
