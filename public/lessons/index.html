教材就是你电脑里的真实项目 E:\zcode\cesium-campus-twin

上课前的准备（只需做一次）

  1. 确认"放映机"开着：整个课程依赖本地服务器。如果浏览器打开课程页是白屏/报错， 打开命令行（Win+R 输入 cmd 回车），执行： 
    cd E:\zcode\cesium-campus-twin
npm run dev
    看到 Local: http://localhost:5173/ 就说明开机了，浏览器访问 http://localhost:5173/lessons/index.html（本页）。
  2. 装一个代码编辑器（推荐 VSCode，免费）：所有课程文件都在 public\lessons\ 文件夹里，用编辑器打开就能改。改完保存，浏览器 F5 刷新看效果。
  3. 学会一件救命技能：页面不对劲时按 F12 打开开发者工具，切到"Console（控制台）"， 红色的字就是错误原因——把第一行红字复制去问 AI，能解决 90% 的问题。
  4. 学习节奏：一天 1–2 课，每课的【动手作业】必须亲手做完再进下一课。课程页顶部的 ✅ 会自动记住你学到哪了。
