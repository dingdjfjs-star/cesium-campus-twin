第 4 课：画出第一栋楼——"平地拔起"的魔法

盒子是"悬浮的箱子"，楼应该"从地里长出来"。这课学数字孪生里最核心的建模手法：画楼底 → 向上拉伸。

先看效果 👇

注意观察:楼是从地面"长"出来的,不像盒子那样悬空

一、思路：先画"脚印"，再向上拉

真实世界的楼 = 一个矩形脚印 × 向上延伸的高度。Cesium 完美复刻这个过程：

① polygon 画脚印(平面多边形)→ ② extrudedHeight 指定拉伸到的海拔→ ③ 楼成!

二、代码与逐行解读

// 教学区用的楼:中心(114.30, 30.50), 东西向60米 × 南北向40米
const C0 = [114.30, 30.50];
const halfLon = 0.00031;  // 30米换算成的经度(怎么算的?往下看"米与度的换算")
const halfLat = 0.00036;  // 20米换算成的纬度

// 四个角:左下 → 右下 → 右上 → 左上(顺时针绕一圈)
const corners = [
  Cesium.Cartesian3.fromDegrees(C0[0] - halfLon, C0[1] - halfLat),
  Cesium.Cartesian3.fromDegrees(C0[0] + halfLon, C0[1] - halfLat),
  Cesium.Cartesian3.fromDegrees(C0[0] + halfLon, C0[1] + halfLat),
  Cesium.Cartesian3.fromDegrees(C0[0] - halfLon, C0[1] + halfLat),
];

viewer.entities.add({
  polygon: {
    hierarchy: new Cesium.PolygonHierarchy(corners), // 脚印:一圈点
    height: 0,                // 脚印放在海拔 0 米(地面)
    extrudedHeight: 64,       // 拉伸到海拔 64 米 → 楼高 64 米
    material: Cesium.Color.fromCssColorString('#3fbdf2').withAlpha(0.8),
    outline: true,            // 描边更清晰
    outlineColor: Cesium.Color.WHITE.withAlpha(0.5),
  },
});
  1. hierarchy 直译"层级"，这里就当"围栏"理解：把一圈点按顺序连起来围出地块。至少 3 个点，本课用 4 个点围出矩形。
  2. height: 0 —— 脚印本身的海拔。普通平地放 0 就行（真实项目放 1 左右，避免和地面"打架"闪烁）。
  3. extrudedHeight: 64 —— 本课主角：把平面脚印向上"挤出"到这个海拔。64 米 ≈ 20 层楼（层高按 3.2 米算：20 × 3.2 = 64）。
  4. fromCssColorString('#3fbdf2') —— 用网页通用的颜色写法（#开头的十六进制）指定颜色，比 Cesium.Color.RED 这种预定义色自由得多。取色器搜"hex color"随便挑。
  5. outline —— 白色描边让楼在深色地球上更精神，科技感就是这么来的。

三、米与度的换算（本课唯一的数学，两行记住）

上面出现 halfLon = 0.00031 这种别扭写法，是因为 hierarchy 的点必须是经纬度，而人类说"楼宽 60 米"。换算口诀：

方向换算30 米在该方向 ≈
南北(纬度)1° 纬度 ≈ 111320 米（任何地方都一样）30 ÷ 111320 ≈ 0.00027°
东西(经度)1° 经度 ≈ 111320 × cos(纬度) 米（越往两极越短）北纬30.5°: 30 ÷ 95300 ≈ 0.00031°
每次都手算太痛苦了！真实项目写了个换算函数 offsetLL(dx, dy) （"向东 dx 米、向北 dy 米，换算成经纬度"），从此只写米不写度——下一课它就是主角。

四、层高小知识（答辩用得上）

建筑层高通常 2.8~4.5 米，教学楼/宿舍按 3.2 米估算很稳。所以：

楼高(米) = 层数 × 3.2
// 6层宿舍 = 19.2米   20层 = 64米   30层 = 96米

数字孪生场景里楼高不必和现实分毫不差，比例正确（教学楼矮、图书馆中、宿舍群齐高）比精确更重要——评委看的是整体气质。

真实项目里每栋楼 = 本课的拉伸体 + 一块同形状的"屋顶盖板"(亮色 polygon 放在楼顶高度,远看像发光楼顶) + 一个头顶 label。打开 sceneObjects.js 搜 extrudedHeight 就能看到一模一样的写法, 只是四角由 rectCorners() 函数算出(它还能旋转楼的角度)。

📝 动手作业

  1. 在你的 my1.html 里,在你学校坐标上盖一栋"教学楼":60×25 米、5 层、你喜欢的颜色,加上描边和标签。
  2. 再紧挨着盖第二栋(把坐标整体向北移 40 米,纬度 +0.00036),组成一个小院落。
  3. 挑战:把 extrudedHeight 改成 0 试试——看到的"一片纸"会让你永远记住这个参数是干嘛的。

检查点

1. 想盖 12 层楼，extrudedHeight 该写多少？

12 × 3.2 ≈ 38.4，写 38 或 39 都行。

2. hierarchy 里 4 个点的顺序重要吗？

重要。要按顺序绕一圈（顺时针或逆时针都行），如果乱序（比如画成蝴蝶交叉），多边形会扭成奇怪的形状。

3. 30 米在"东西方向"和"南北方向"换算成度，哪个大？

东西方向的度数更大（因为经度圈越往极地越小，一度装的米数少，同样的米数就要更多的度）。
