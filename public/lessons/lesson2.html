第 2 课：坐标与相机——给地球上的点"定位"

三维世界的第一门外语：经纬度。学完这课，你能让相机飞到地球上任何地点，还懂了"高度"这个第三维度。

先玩一玩：输入坐标，飞过去 👇

左边输入框：经度 / 纬度 / 高度米。试着只改高度 3000 → 300 → 30000，感受"米"

一、经纬度：地球的门牌号

想象给地球横着画一圈圈线（纬度）、竖着画一圈圈线（经度），任何地点都是"某横线与某竖线的交点"：

经度 lon纬度 lat
方向东西方向（本初子午线=0°，向东为正）南北方向（赤道=0°，向北为正）
范围−180° ~ +180°（东经为正，西经为负）−90° ~ +90°（北纬为正，南纬为负）
中国典型值约 73° ~ 135°（北京 116.4）约 18° ~ 53°（北京 39.9）
精度速记：小数点后第 5 位 ≈ 1 米。所以写坐标时保留 5 位小数就够精确了， 比如 116.39120, 39.90750。只有前 2 位（如 116.39）的话会差出好几公里。

二、第三维度：高度（米）

经纬度定"平面位置"，高度定"离地多少米"，三者合起来才是三维空间里的一个点。Cesium 的标准写法（务必背下来）：

Cesium.Cartesian3.fromDegrees(经度, 纬度, 高度米)
// 例:天安门上空 2000 米
Cesium.Cartesian3.fromDegrees(116.3912, 39.9075, 2000)
  1. Cartesian3 直译"笛卡尔坐标"，是引擎内部的坐标格式（三个数字 x/y/z）。你不用理解内部原理，只要知道 fromDegrees 是"翻译官"，把人类友好的经纬度翻译给它。
  2. 三个参数顺序固定：经度在前，纬度在后——新手最常犯的错就是写反，写反了会飞到地球另一边（对称点），出现"我明明想去北京却在南美"的灵异事件。
  3. 高度不写默认 0（贴地）。相机高度就是"你站在多高往下看"。

三、setView 瞬移 vs flyTo 飞行

// 瞬移:0 秒到达,页面一打开就在这(适合"初始视角")
viewer.camera.setView({ destination: Cesium.Cartesian3.fromDegrees(116.39, 39.9, 5000) });

// 飞行:默认约 3 秒平滑飞达(适合"演示动作",电影感)
viewer.camera.flyTo({ destination: Cesium.Cartesian3.fromDegrees(116.39, 39.9, 5000) });
场景用哪个
页面加载后的初始位置setView（用户不该看见"起飞过程"）
点按钮"飞到某楼"flyTo（让评委看到镜头移动 = 高级感）
开场大动画(从太空俯冲进校园)先 setView 到太空,再延时 flyTo 冲下来(真实项目就这么干的)

四、朝向三兄弟：heading / pitch / roll（了解即可）

flyTo 的第二个参数 orientation（朝向）里有三个角度，用"开飞机"比喻：

参数比喻常用值
heading摇头(朝哪个方向看,0=北,90=东)0°
pitch点头(低头俯视还是平视)−90°=正俯视,−45°=斜视(最常用)
roll歪头(一般不用)0°

演示区"斜着看"按钮的代码：

viewer.camera.flyTo({
  destination: Cesium.Cartesian3.fromDegrees(114.9347, 25.7810, 2500),
  orientation: { heading: 0, pitch: Cesium.Math.toRadians(-45), roll: 0 } // -45° 斜着看城市
});
角度单位陷阱：Cesium 内部用弧度，你脑子里想的是度。中间用 Cesium.Math.toRadians(度数) 换算，忘写它是最常见的"为什么我的 -45° 没反应"的原因。

五、怎么查一个地方的坐标？

  1. 高德坐标拾取器：搜索"高德地图坐标拾取器"（lbs.amap.com/tools/picker），找到地点，页面上就显示坐标，复制过来用。
  2. 注意高德/百度用自家加密坐标（GCJ02/BD09），和 Cesium 用的 WGS84 会有几百米偏移——教学和城市级演示无感，要做到楼级精准需用 WGS84 坐标源（如天地图）。
  3. 懒得查？演示页输入框里已预填了一组中国南方城市坐标，直接点"飞过去"。
真实项目里,校园原点写在 campusData.js 的 CAMPUS = { lon: 114.30, lat: 30.50 }, 想把整座校园搬到任何真实地点,改这两个数字即可——第 5 课会看到为什么一个点能撬动整座校园。

📝 动手作业

  1. 用高德拾取器查出你学校的坐标，填进演示页输入框，点"飞过去"，从 3000 米、1000 米、500 米三个高度各看一眼。
  2. 在你的 my1.html 里加一个按钮：先 setView 到 50000 米太空，停 1 秒后 flyTo 俯冲到 2000 米（提示：setTimeout(()=>{...},1000)）。
  3. 挑战：把经纬度故意写反，飞过去看看自己到了地球哪儿（再用高德查查那是哪国）。

检查点

1. fromDegrees(39.9, 116.39, 1000) 错在哪？

经纬度写反了。正确顺序是 (经度, 纬度, 高度)，应为 fromDegrees(116.39, 39.9, 1000)。

2. 想要"打开页面瞬间就在校园上空 45° 斜视"，用 setView 还是 flyTo？

setView（瞬移）。flyTo 会让你看见起飞过程，初始视角一般不想要这个。

3. 高度 100 和 10000 的区别，用你的话讲是什么？

100 米≈30 层楼楼顶视角（能看清一栋楼），10000 米≈民航巡航高度（能看清一座城）。数字的单位永远是米。
